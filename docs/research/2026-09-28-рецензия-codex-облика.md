### Замечания

1. **Нельзя вернуть Claude уровень «по умолчанию».** [panel.js](C:/Users/21435/source/agent-panel/media/panel.js:774) сбрасывает `effort` только при выборе узла, совпадающего с `defaultEffort`. Каталог Claude его не сообщает. После выбора, например, «Высокое» в той же модели нет действия, отправляющего пустой `effort`; прежний список такое действие имел. **Уверенность:** проверено чтением.

2. **Отказ человека не окрашивает бусину и не увеличивает счётчик отказов Claude.** [panel.js](C:/Users/21435/source/agent-panel/media/panel.js:408) находит карточку по `request_id` и выходит до обновления вызова. Бусина хранится по другому ID — `tool_use_id` ([claude.ts](C:/Users/21435/source/agent-panel/src/adapters/claude.ts:523)). При «Отклонить» вызов останется выполняющимся либо результат пометит его как «готово». Тест ошибочно использует один ID для карточки и вызова. **Уверенность:** проверено чтением реальных полей адаптера.

3. **Один инструмент Codex даёт две бусины.** [panel.js](C:/Users/21435/source/agent-panel/media/panel.js:393) сопоставляет начало и результат по `callId`, но [codex.ts](C:/Users/21435/source/agent-panel/src/adapters/codex.ts:532) не передаёт его ни в одном событии. На `item/completed` создаётся второй вызов; первый остаётся «готовится». Счётчики тоже удваиваются. **Уверенность:** проверено чтением.

4. **Эстафета скрывает новый прямой ответ после принятой задачи.** [thread.js](C:/Users/21435/source/agent-panel/media/thread.js:242) выбирает `accepted` раньше проверки `claudeBusy`/`codexBusy`. Прямое сообщение после цикла не сбрасывает этап в [coordinator.ts](C:/Users/21435/source/agent-panel/src/coordinator.ts:203). Пока агент отвечает, шапка продолжает показывать «Работа принята». **Уверенность:** проверено чтением и вызовом `relayView` без записи файлов.

5. **Оформленный вердикт может противоречить вердикту цикла.** [thread.js](C:/Users/21435/source/agent-panel/media/thread.js:313) считает ограды кода по чётности, не учитывая их длину. Для блока, открытого четырьмя обратными кавычками и затем содержащего строку из трёх, UI оформляет последующее `ВЕРДИКТ: ПРИНЯТО` как принятие. [verdict.ts](C:/Users/21435/source/agent-panel/src/verdict.ts:55) правильно оставляет блок открытым и возвращает `missing`. **Уверенность:** воспроизведено вызовом `verdictLine` без записи файлов.

6. **Клавиатурный фокус теряется при выборе режима.** [panel.js](C:/Users/21435/source/agent-panel/media/panel.js:538) пересоздаёт все кнопки после выбора; при выборе пункта меню удаляется и сфокусированная кнопка ([panel.js](C:/Users/21435/source/agent-panel/media/panel.js:561)).
