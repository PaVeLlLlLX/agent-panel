# История изменений Agent Panel

Что было найдено в живых прогонах и рецензиях и как это исправлено. Устройство
панели — в [устройство.md](устройство.md).

### Ночь на 28 сентября: рецензии Codex и живые трассы

Каждая новая функция ночью уходила на рецензию Codex (`codex exec`, только
чтение); все замечания сверены по коду, воспроизведены тестом и закрыты.
Тексты рецензий — `docs/research/2026-09-28-рецензия-codex-*.md`.

| Что было | Следствие | Как закрыто |
|---|---|---|
| рецензенту уходил текст, обрезанный для показа | пометка «сырой вывод» завышала полноту | полный вывод с заголовком полноты, бюджет на проверку |
| фоновый субагент Claude: `result` до конца его работы | рецензент получил бы «агент запущен, жду», итог — без проверки | ход держится до итога; живая трасса в `docs/research` |
| отказ человека не окрашивал бусину | карточка по `request_id`, бусина по `tool_use_id` | `toolCallId` у разрешений |
| инструмент Codex давал две бусины | нет id у `tool_call`/`tool_result` | `callId` из id элемента |
| «Работа принята» при ответе на прямой вопрос | этап проверялся раньше занятости | занятость раньше |
| оформленный вердикт расходился с вердиктом цикла | ограды кода по чётности | по виду и длине, как `verdict.ts` |
| у Claude нельзя вернуть уровень «по умолчанию» | умолчание неизвестно, узлом не выбрать | ссылка «вернуть по умолчанию» |
| сообщение уходило после «Остановить» во время поиска памяти | нет проверки остановки после ожидания | счётчик остановок |
| журнал терял `toolCallId` и `parentCallId` | после перезапуска связи пропадали | колонки с миграцией |
| расход Codex отрицательный после сжатия, чужой после возобновления | разность итогов без `turnId` и без переноса | свой `turnId`, перенос при сбросе |
| субагент, не сообщивший о конце, держал ход вечно | ждали только уведомления | срок тишины 10 мин, затем остановка процесса |
| фоновая команда кончилась — CLI сам начал ход (живая трасса) | ход принимался за ответ на следующее сообщение | «самостоятельный» ход: не занимает цель, не идёт рецензенту |
| сообщение ушло, когда CLI уже начал свой ход | метки ходов менялись местами | эхо `--replay-user-messages`; живьём — посредник, придерживающий `init` |
| ошибка своего запроса до эха, субагент или поток чужого | ход ждал вечно или чужое продолжение шло рецензенту | чужой — запрос без эха с ответом; субагенты чужого — отдельно |
| «Прервать» при сообщениях в очереди | очередь висела; после — гонка с поздним концом хода Codex | очередь снимается с сообщением; прерванные ходы Codex — набором |
| прерывание во время запуска Codex, повторное прерывание | ход начинался после «Прервать» или прерывался прежний | занят с начала отправки, ход забывается сразу |
| `/usage` из каталога проекта (замер) | запускал хук SessionStart проекта | пустой временный каталог |
| путь к команде с пробелом под cmd.exe | делился на слова | кавычки вокруг существующего пути |

### По прогону 16 сентября на рабочей задаче

| Что было | Следствие | Как закрыто |

| действия, требующие согласия, отклонялись молча | работа стояла, панель ждала «Повторить Claude» | карточка разрешения: `--permission-prompt-tool stdio` |
| Markdown и формулы агентов показывались сырым текстом | таблицы и формулы нечитаемы | markdown-it + KaTeX в сборке панели, своё правило границ `$…$` |
| модель и уровень рассуждения не выбирались | всё шло на моделях CLI по умолчанию | кнопка «Модели»: списки у агентов, смена со следующего хода |
| разбор вердикта переключал признак кода на любой строке с тремя кавычками | пример формата в ответе рецензента мог закрыть цикл: пять входов давали ложное «принято» | ограда запоминается видом и длиной; отступ кода и обратные кавычки вердиктом не считаются |

| рецензент считал обмен законченным, но мог поставить только «есть замечания» | третья проверка ушла на пересылку согласий | вердикт «нужно решение человека» |
| замечания подписывались версией, снятой после проверки | правки во время проверки делали старые замечания похожими на новые | подпись проверенной версией и строка о сдвиге |
| в `verdict.ts` попал нулевой байт вместо `\u0000` | git показывал файл двоичным, парсер нельзя было рецензировать по diff | метка строк кода — `null`; тест на нулевые байты во всех файлах |

### По журналам прогона 15 сентября и рецензии кода

| Что было | Следствие | Как закрыто |
|---|---|---|
| отказ в разрешении считался законченной работой | три проверки ушли на спор о заблокированной команде | отказы не идут на проверку; «Повторить Claude» |
| вердикт искался словом в любом месте ответа | `НЕПРИНЯТО` и цитата засчитывались как приёмка | только последняя строка, только точное значение |
| продолжение цикла не знало, что задача сменилась | ответ по старой задаче уходил в новую | номер цикла, проверка после каждого ожидания |
| цель хода записывалась после отправки | быстрый ход оставался без цели | цель до отправки, снятие при ошибке |
| «Прервать» оставлял пересылки в очереди | после прерывания они всё равно уходили | очередь чистится от чужих циклов |
| `kill` на Windows завершал только `cmd.exe` | агент и его команды жили после «Остановить» | `taskkill /T /F` и ожидание выхода |
| поздний выход старого Codex гасил новый запуск | перезапуск рецензента срывался | контекст на каждый процесс |
| второе сообщение во время запуска терялось | вопрос без ответа | общее ожидание готовности |
| ошибки записи в stdin не показывались | молчащий агент | сбой канала завершает ход с ошибкой |
| «раунды», «автораунды», «проверки» вперемешку | непонятно, что считается | одно слово на понятие, подсказки, словарь |
| запуск только через F5 во втором окне | неудобно пользоваться | установка из `.vsix` |

### По разбору рецензента

| Дефект | Следствие | Как закрыт |
|---|---|---|
| `thread/start` возвращает `thread.id`, код читал `threadId` | первая отправка падала | имена из схемы; тест на фальшивом сервере |
| тип элемента `agentMessage`, код искал `agent_message` | ответ рецензента отбрасывался | имена из `ThreadItem` |
| не было обработчика `item/agentMessage/delta` | поток рецензента не показывался | обработчик дельт |
| один накопитель на двух агентов | подмена авторства реплик | накопители по агенту |
| очередь выгружалась с конца | обратный порядок сообщений | порядок поступления |
| «Прервать» выключало Claude насовсем | «адаптер не запущен» | перезапуск с `--resume` |
| новые файлы входили в отпечаток только именами | правка не меняла версию | хеши содержимого |
| `session_id` сохранялся до появления | старая история с новой сессией | обратные вызовы `onSessionId` |
| полный вывод терялся за обрезкой | окончание вывода недоступно | поле `raw` в журнале |
| `npm test` искал файлы другого расширения | заявленные тесты не запускались | штатное обнаружение |

### По живому прогону 14 сентября

Журнал комнаты сохранил 1 850 событий за 9 минут; всё ниже установлено по
нему и по транскрипту сессии, а не по впечатлению.

| Что увидели | Причина | Как закрыто |
|---|---|---|
| Claude спорил с уже отозванным замечанием | «Оба» + параллельные ходы + очередь | три маршрута, строгая очерёдность в рецензии |
| проверка посреди обмена осталась без ответа | цикл кончался только по счёту | вердикт рецензента, удержание недоставленного |
| «Предел раундов» подписан «Вы» | служебное от имени человека | автор `system`, подпись «Панель» |
| красная реплика с `[2m…[0m` | stderr Codex как ошибка беседы | диагностика, цветовые коды вычищаются |
| пол-панели под действиями | карточка на каждый вызов | одна строка на ход, подробности по клику |
| две заметки в хранилище, пробный файл в репозитории | глобальные хуки в сессии панели | `--setting-sources project,local` |
| сессия Claude от простого открытия панели | запуск при открытии | запуск при первом сообщении |
| «процесс завершился: SIGTERM» при закрытии | плановая остановка как авария | остановка — диагностика |

И найдено по ходу, до падения: без обработчиков `error` на процессе и stdin
ненайденная команда или запись в умерший процесс роняли хост расширений
VS Code целиком. Закрыто, есть тесты для обоих адаптеров.
