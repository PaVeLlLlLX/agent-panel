# Проверки рецензентов и исправления по журналу — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Рецензенты Codex и Gemini проверяют свои утверждения скриптами в песочнице, не трогая проект и данные; плюс шесть исправлений, найденных в журнале 04–05.10.

**Architecture:** Codex получает свою ветку на комнату, читает репозиторий командами и (ступень 2) пишет и запускает скрипты в папке вне репозитория под профилем прав «читать всё, писать в папку, сеть выключена» с самопроверкой и откатом. Скрипты Gemini панель выполняет коротким процессом `codex app-server` через `command/exec` и возвращает вывод вторым ходом. Исправления: вопрос Claude доходит до человека, итог приёмки уходит Claude со следующим сообщением, журнал хранит действия человека и расход, Gemini повторяет ход при сетевом сбое, разногласие рецензентов видно, «новая сессия» не лжёт.

**Tech Stack:** TypeScript (VS Code extension), Node 24 `node:test`, `node:sqlite`, codex app-server JSON-RPC (0.159), Antigravity CLI `agy`.

**Spec:** `docs/specs/2026-10-05-проверки-рецензентов.md`. Исправления по журналу (задачи 1–5) согласованы с владельцем в беседе 05.10 (список из шести пунктов).

## Review Focus

1. Ход Codex, прерванный стоп-сигналом: адаптер глотает поздний `turn_completed` прерванного хода (`codex.ts` `#interrupted`), значит координатор сам снимает цель, буфер и пару — цикл не должен висеть в «проверяют». Тест в задаче 8.

4. Codex обновился, и app-server не принимает профиль прав: проверка всё равно идёт в «только чтение», цикл не падает. Тест в задаче 9.
5. Ответ человека на `AskUserQuestion` доходит до Claude ответами (не «did not answer»), в том числе в режиме «без вопросов»; «Прервать»/«Остановить» закрывают открытую карточку вопроса. Тест в задаче 1.
