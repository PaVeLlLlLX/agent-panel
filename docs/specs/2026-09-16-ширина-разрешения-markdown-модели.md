# Ширина, разрешения, Markdown, модели

Согласовано с владельцем 16.09.2026 по живому прогону панели на рабочей задаче.
Порядок работ: 1 → 2 → 3 → 4, каждая часть — тесты и отдельный коммит.

## 1. Панель не расширяется от длинной строки

**Наблюдение.** Промпт с логом в одну строку сделал панель шире окна:
горизонтальная прокрутка, кнопки за краем.

**Причина (по CSS).** `body` — сетка без `grid-template-columns`; неявная
колонка берёт ширину по содержимому, а `.задача` с `white-space: nowrap`
растягивает её на всю строку.

**Решение.** Колонка `minmax(0, 1fr)`; строка задачи обрезается многоточием,
полный текст в `title`; причина удержания переносится (`overflow-wrap:
anywhere`) и прокручивается при большой высоте.

**Проверка.** Безголовый браузер на разметке панели с длинной задачей:
`scrollWidth` документа не больше ширины окна. До исправления — больше.

## 2. Запрос разрешений Claude

**Установлено пробой** (CLI 2.1.220). С `--permission-prompt-tool stdio` Claude
пишет в stdout:

```json
{"type":"control_request","request_id":"…","request":{"subtype":"can_use_tool",
 "tool_name":"Bash","display_name":"Bash","input":{"command":"…","description":"…"},
 "description":"…","permission_suggestions":[{"type":"addRules","rules":[…],
 "behavior":"allow","destination":"localSettings"},{"type":"addDirectories",…,
 "destination":"session"},{"type":"setMode","mode":"acceptEdits","destination":"session"}],
 "blocked_path":"…","tool_use_id":"toolu_…"}}
```

Ответ панели в stdin:

```json
{"type":"control_response","response":{"subtype":"success","request_id":"…",
 "response":{"behavior":"deny","message":"…"}}}
```

Отказ доходит до модели как `tool_result` с `is_error: true` и попадает в
`permission_denials` итога. Разрешение — `{"behavior":"allow","updatedInput":…}`
по контракту Agent SDK; живой прогон разрешения пробой не делался намеренно
(владелец отклонил пробу, которая сама разрешала команду) — проверяется в
первом живом прогоне панели.

**Решение.**
- Адаптер Claude запускается с `--permission-prompt-tool stdio`, переводит
  `can_use_tool` в событие `permission_request` и принимает ответ
  `answerPermission(id, решение)`.
- Кнопки: **Разрешить**, **Разрешить в этой сессии**, **Отклонить**.
  «В этой сессии» передаёт в `updatedPermissions` только предложения с
  `destination: "session"`; правила с `localSettings` панель не пишет —
  решение владельца, в файлы настроек ничего не попадает.
- Этап «ждёт разрешения»; проверки не расходуются.
- «Прервать» и «Остановить» отклоняют открытые запросы; падение процесса
  закрывает их карточки.
- Каждый запрос и решение — в журнал.
- Удержание с «Повторить Claude» остаётся для отказов без запроса
  (режимы `dontAsk` и подобные).

## 3. Markdown и формулы

- `markdown-it` (`html: false`, `linkify`) + `@vscode/markdown-it-katex` + KaTeX;
  файлы копируются в `media/vendor` при сборке, CSP: `font-src` и `style-src`
  источника webview, внешних загрузок нет.
- Отрисовываются реплики агентов; сообщения человека и вывод команд — как
  есть.
- Ссылки открываются через расширение (`vscode.env.openExternal`).
- Вердикт читается из исходного текста.

## 4. Модель и уровень рассуждения

- **Claude:** список из ответа `initialize` (`models[].value`,
  `supportedEffortLevels`); смена — между ходами перезапуском с
  `--resume --model --effort`.
- **Codex:** список из `model/list` (`model`, `supportedReasoningEfforts`,
  `isDefault`); смена — полями `model` и `effort` в `turn/start`.
- Выбор хранится для комнаты; посреди хода не применяется.
- Перечень `claudePermissionMode` приводится к CLI: `acceptEdits`, `auto`,
  `bypassPermissions`, `manual`, `dontAsk`, `plan`.
