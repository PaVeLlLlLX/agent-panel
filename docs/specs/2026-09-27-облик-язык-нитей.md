# Облик панели: язык нитей

Согласовано с владельцем 27.09.2026 на холсте Claude Design
(https://claude.ai/artifact/99hLKrGUXxWqRXiNb4vau9, приватный; копия исходников
артбордов — `docs/design/`). Владелец выбрал **вариант 2** всей комнаты,
шкалу уровня рассуждения **«Нить»** и **все** элементы ряда «Элементы на языке
нитей». Основная тема — тёмная, светлая обязательна.

## Язык

- **Огоньки — участники.** Claude — тёплый, Codex — холодный, человек — белый.
  Один и тот же цвет агента везде: статус, режимы, бусины, шкала.
- **Нити — связи**, **частицы на нити — работа**. Чем больше работы, тем
  больше и быстрее частицы.
- **Смысл передаёт форма, а не подписи.** Определения — во всплывающих
  подсказках, не в интерфейсе. Владелец прямо просил не нагружать текстом.
- **Цвета почти нет.** Интерфейс серый; цвет только у агентов, у внимания
  (янтарный), у ошибок (красный) и у уровня рассуждения.

### Токены

Тёмная тема (светлая — `docs/design/Main2.dc.html`, класс `.v-light`):

| Токен | Значение | Роль |
|---|---|---|
| фон | `#1B1B1B` | панель |
| поверхность | `#242424` | поле ввода, карточки, всплывающие окна |
| приподнятая | `#2F2F2F` | пузырь человека |
| вдавленная | `#161616` | блоки кода, команда в карточке разрешения |
| линия | `rgba(255,255,255,.08)` | единственная рамка |
| текст / сильный / тихий / едва | `#D6D6D6` / `#F4F4F4` / `#8E8E8E` / `#6A6A6A` | |
| главная кнопка | `#ECECEC` на `#161616` | «Отправить», «Разрешить» |
| второстепенная кнопка | `#333333` | пилюли |
| Claude | тёплая гамма `#8C7C70 → #AE8868 → #C99264 → #DE9C60 → #F0A862 → #FFC27A` | |
| Codex | холодная гамма `#6F808C → #5B94A6 → #4FA7B6 → #4CB9C3 → #5BCBD0 → #9AE6EA` | |
| внимание / успех / ошибка | `#E6B450` / `#7CC98A` / `#F2877A` | |

В коде панели фон, поверхности и текст выводить из токенов VS Code через
`color-mix()` (например, поверхность = 6% `--vscode-foreground` поверх
`--vscode-editor-background`), чтобы панель жила в любой теме. Цвета агентов и
состояний — свои, с парой значений для светлой темы.

## Элементы и где они живут

| Элемент | Артборд | В панели |
|---|---|---|
| Комната целиком | `Main2`, `Light2` | вся разметка webview |
| Шкала уровня рассуждения | `Filament`, `EffortVariants` | всплывающее окно «Модели», по карточке на агента |
| Статус «Эстафета» | `Status` (верхняя карточка) | шапка, всегда видна |
| Статус «Дорожка цикла» | `Status` (нижняя карточка) | раскрывается по клику на «Эстафету»: история кругов |
| Режим: переключатель | `Route` (верх) | панель поля ввода, при ширине ≥ 420 px |
| Режим: меню | `Route` (низ) | по клику на название режима и при узкой панели |
| Действия: «Чётки» | `ActionsChain` (верх) | свёрнутая строка хода, слева |
| Действия: «Счётчики» | `ActionsChain` (низ) | та же строка, справа; «выполняется: …» переливается |
| Запрос разрешения | `Permission2` | карточка в беседе |
| Ждёт вашего решения | `Held2` | плашка над полем ввода |

### Шкала «Нить»

- **Уровни:** Claude — Низкое, Среднее, Высокое, Очень высокое, Максимум и
  отдельно, за пунктиром, **Ultracode**; Codex — те же пять и **Ультра**.
  Реальный набор берётся из каталога моделей (`listModels`), как сейчас: у
  Haiku уровней нет, у GPT-6 Luna нет «Ультра».
- **Смысл формой:** частицы к выбранному узлу, чем выше — тем больше и быстрее;
  «Максимум» — линия толще и двойное кольцо (глубина в одном рассуждении);
  «Ультра» и Ultracode — нить ветвится на три ветки с огоньками субагентов на
  концах (ширина за счёт параллельных агентов). Чёрточка под узлом — уровень
  по умолчанию.
- **Подсказки узлов** — определения из документации:
  [Anthropic](https://platform.claude.com/docs/en/build-with-claude/effort),
  [OpenAI](https://learn.chatgpt.com/docs/models),
  [Ultracode](https://academy.claude.com/tutorials/choosing-the-right-effort-level-in-claude-code).
  Тексты — в `docs/design/Filament.dc.html`.
- **Не проверено:** доступен ли Ultracode в режиме `claude -p`, которым панель
  запускает Claude, и каким флагом. Проверить пробой до показа узла; нет —
  узел не показывать.

### Статус

Этапы координатора → вид: `working` → частицы к Claude; `reviewing` → к
Codex; `held` и открытые запросы разрешений → белый огонёк человека
посередине, частицы стоят; `accepted` → нить залита тёплым-холодным, галочка;
`stopped` / `idle` → нить тусклая, без частиц. Три точки справа — «проверок N
из M» (M — `maxAutoRounds`). «Дорожка цикла» строится из журнала комнаты:
каждая пересылка — узел, у узлов Codex — отметка вердикта (`!`, `?`, `✓`).

### Действия

Бусина на каждый вызов инструмента: форма по виду (`PanelFormat.toolCategory`:
команда — квадрат, чтение — кольцо, правка — ромб, прочее — точка), цвет по
состоянию (`вызов сформирован` — пустая, `выполняется` — белая пульсирует,
`результат получен` — цвет агента, `отказано` — красная). Подсказка бусины —
инструмент и аргумент. Счётчики справа — те же категории с числами.

### Прочее из варианта 2

- Шапка: статус, «Прервать» и «Остановить» — круглые значки с подсказками;
  строка задачи тихим текстом.
- Беседа: пузырь человека справа, реплики агентов без рамок, над ними имя и
  версия; вердикт — значок и слова («Есть замечания»), под ними мелко исходная
  строка `ВЕРДИКТ: …` — она должна оставаться видимой.
- Поле ввода — одна скруглённая поверхность: текст, режим, «Без вопросов» со
  щитом, «Модели» (значок — две полоски, тёплая и холодная), круглая
  «Отправить». Ниже: «Автопересылка», «Диагностика».
- Кнопка «↓ К последнему» (уже в `8148cd9`) — в том же стиле, пилюлей.

## Анимация

Только CSS `@keyframes`, без таймеров в JS. Все анимации выключаются при
`prefers-reduced-motion: reduce` (частицы скрываются, пульс и перелив стоят).
Частицы — абсолютно позиционированные точки с `animation-delay` < 0 для
равномерного потока.

## Ограничения, которые нельзя нарушить

- CSP webview: скрипты только с nonce, без внешних шрифтов и картинок.
- Узкая колонка 480–600 px без горизонтальной прокрутки (тест ширины).
- Одно слово — одно понятие: названия из словаря README сохраняются.
- Вердикт читается из исходного текста; отрисовка на него не влияет.
- Поведение не меняется: все 153 существующие проверки должны проходить.

## План реализации

1. Токены и базовая раскладка (`media/panel.css`, разметка в `src/extension.ts`).
2. Беседа, поле ввода, карточка разрешения, «ждёт вашего решения».
3. Компонент нити как чистые функции в отдельном модуле (`media/thread.js`,
   по образцу `format.js`): позиции узлов, выбор цвета, число и скорость
   частиц, ветвление — с unit-тестами в node. Разметка строится из них.
4. Шкала «Нить» во всплывающем окне «Модели» вместо двух выпадающих списков.
5. Статус «Эстафета» и «Дорожка цикла» (данные — `RoomState` плюс история
   пересылок из журнала).
6. Режим: переключатель и меню.
7. «Чётки» и «Счётчики».
8. README: раздел об облике; `npm run package`, установка.

**Проверка вида.** Безголовый Edge 153 на этой машине не отдаёт вывод
(`--dump-dom` и даже `--version` молчат), поэтому браузерные тесты
пропускаются. До реализации стоит вернуть рабочий браузер для тестов —
например, `chrome-headless-shell` через `npx @puppeteer/browsers` — иначе вид
проверяется только глазами владельца.

**Расход.** Работа большая; делать свежей сессией, не продолжением длинной:
по `/usage` 98% расхода Claude идёт на запросы длиннее 150 тыс. токенов.
Граница владельца — не более 90% недельного лимита.
