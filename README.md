# Agent Panel

Расширение VS Code для работы одновременно с Claude Code и Codex. Оба агента
отвечают в одной ленте, их действия видны там же, а Codex может проверять
работу Claude по полному выводу его команд, а не по пересказу.

Панель не привязана к конкретному проекту или языку: агенты работают в папке,
открытой в окне VS Code.

## Возможности

- Четыре режима отправки: задача с рецензией, вопрос обоим агентам, только
  Claude, только Codex.
- Цикл рецензии: Claude выполняет задачу, Codex проверяет её и выносит вердикт;
  при замечаниях работа возвращается к Claude. Число проверок ограничено.
- Рецензент видит полный вывод команд Claude. Каждое замечание помечено версией
  файлов, которую он проверял.
- Запросы разрешений Claude приходят в ленту карточками с кнопками.
- Модель и уровень рассуждения выбираются отдельно для каждого агента.
- Можно продолжить уже существующую сессию Claude Code или ветку Codex.
- К сообщению можно автоматически прикладывать заметки из памяти проекта.
- Расход токенов по задаче и доля недельных лимитов обоих агентов.
- Всё, что происходит в комнате, записывается в локальный журнал.

## Требования

- VS Code 1.90 или новее. Журнал хранится во встроенном модуле `node:sqlite`,
  поэтому среда расширений VS Code должна работать на Node.js 22.5 или новее.
  Проверено на VS Code 1.139.
- Node.js 22.5 или новее и npm — для сборки.
- Claude Code с выполненным входом: расширение Claude Code для VS Code или CLI
  `claude` в `PATH`.
- Codex с выполненным входом: расширение ChatGPT для VS Code или CLI `codex` в
  `PATH`.
- Git желателен, но не обязателен: без него версия файлов считается по их
  содержимому.

Панель проверялась на Windows 10. На macOS и Linux она не запускалась.

## Установка

Если у вас уже есть собранный пакет `agent-panel.vsix`:

```
code --install-extension agent-panel.vsix
```

Сборка из исходников:

```
git clone https://github.com/PaVeLlLlLX/agent-panel.git
cd agent-panel
npm install
npm run package
code --install-extension agent-panel.vsix --force
```

После установки перезагрузите окно: `Ctrl+Shift+P` → «Developer: Reload Window».

Чтобы обновить панель, получите новую версию (`git pull`), снова выполните
`npm run package` и установку с `--force`, затем перезагрузите окно.

## Первый запуск

1. Откройте в VS Code папку проекта. Агенты работают в первой папке окна.
2. Нажмите `Ctrl+Shift+P` и выберите «Agent Panel: открыть комнату».
3. Напишите задачу и отправьте её. По умолчанию выбран режим «Задача с
   рецензией».

Агенты запускаются при первом сообщении, а не при открытии панели. Комната
привязана к папке: если открыть её снова, панель продолжит те же сессии агентов.

Какие программы запускаются:
- **Claude** — `claude` из расширения Claude Code, та же версия, что в вашем чате
  Claude Code; если расширения нет, `claude` из `PATH`.
- **Codex** — `codex` из расширения ChatGPT; если расширения нет, `codex` из
  `PATH`.

Явный путь в настройках `agentPanel.claudeCommand` и `agentPanel.codexCommand`
важнее обоих вариантов.

## Работа с панелью

### Режимы отправки

Режим выбирается переключателем в поле ввода.

| Режим | Что происходит |
|---|---|
| Задача с рецензией | Claude выполняет задачу, затем Codex её проверяет, строго по очереди |
| Спросить обоих | оба агента отвечают независимо, друг другу ничего не передаётся |
| Только Claude | вопрос одному Claude, без проверки |
| Только Codex | вопрос одному Codex |

Чтобы Codex проверил коммит или результат команды, используйте «Задачу с
рецензией». Рецензент сам команды не запускает и видит только то, что вывели
команды Claude.

### Цикл рецензии

1. Claude получает задачу и выполняет её.
2. Codex получает вашу задачу, ответы Claude и полный вывод его команд и выносит
   вердикт.
3. «Принято» — задача закрыта. «Есть замечания» — работа возвращается к Claude, и
   цикл повторяется. «Нужно решение человека» — панель останавливает обмен и ждёт
   вас.

Вердиктом считается только последняя строка ответа Codex, если она ровно одна из
трёх: `ВЕРДИКТ: ПРИНЯТО`, `ВЕРДИКТ: ЕСТЬ ЗАМЕЧАНИЯ`, `ВЕРДИКТ: НУЖНО РЕШЕНИЕ ЧЕЛОВЕКА`.
Если вердикта нет, решение остаётся за вами.

Число проверок на одну задачу задаёт `agentPanel.maxAutoRounds` (по умолчанию 3).
Прогресс цикла виден в строке статуса вверху; по щелчку раскрывается дорожка со
всеми передачами и расходом токенов.

### Когда панель ждёт вас

Панель не передаёт работу дальше, а показывает над полем ввода причину и
кнопку, если:

| Причина | Кнопка |
|---|---|
| Claude получил отказы в разрешениях, и работа не сделана | «Повторить Claude» |
| рецензент просит вашего решения или не вынес вердикт | «Отправить Claude» |
| достигнут предел проверок, работа осталась непроверенной | «Отправить Codex» |
| автопересылка выключена | «Отправить» тому, кому предназначено |

Флажок «Автопересылка» под полем ввода управляет тем, передают ли агенты работу
друг другу сами.

### Разрешения Claude

По умолчанию Claude работает без вопросов. Кнопка со щитом в поле ввода
переключает режим на «спрашивать»; выбор запоминается для папки. В этом режиме
действия, которым нужно ваше согласие, приходят в ленту карточками:

| Кнопка | Что происходит |
|---|---|
| Разрешить | этот вызов, один раз |
| В этой сессии | этот вызов и такая же команда до остановки Claude; в файлы настроек ничего не пишется |
| Больше не спрашивать | этот вызов и режим «без вопросов» для папки |
| Отклонить | отказ; Claude узнаёт, что отказал человек |

Codex всегда работает в песочнице только для чтения и файлы не меняет.

### Модели и уровни рассуждения

Кнопка «Модели» в поле ввода открывает по карточке на агента: модель выбирается
из списка, который сообщает сам агент, уровень рассуждения — на шкале. Выбор
действует со следующего ответа и запоминается для папки; контекст сессии при
этом сохраняется.

### Сессии агентов

Каждая комната помнит свою сессию Claude и ветку Codex. Команды «Agent Panel: новая
сессия Claude для комнаты» и «… Codex для комнаты» начинают новую сессию, а старая
остаётся в истории агента. Лента панели при этом сохраняется.

Панель может продолжить и ваш собственный чат: сессию Claude Code или ветку Codex.
Для этого её идентификатор записывается в таблицу `rooms` журнала (поля
`claude_session` и `codex_thread`). Сам чат нужно закрыть: у одной сессии не
должно быть двух пишущих сторон одновременно.

### Память проекта

Если задана команда `agentPanel.memorySearchCommand`, панель передаёт ей текст
каждого вашего сообщения и прикладывает найденные заметки обоим агентам.
Протокол такой же, как у хука `UserPromptSubmit` Claude Code:
- на вход — JSON `{cwd, prompt}`;
- на выход — `hookSpecificOutput.additionalContext`.

В ленте видно, какие заметки приложены. Если поиск не уложился в 10 секунд или
упал, сообщение уходит без них.

Claude в панели запускается без ваших пользовательских настроек, поэтому ваших
MCP-серверов у него нет. Нужные серверы передайте файлом
`agentPanel.claudeMcpConfig` в формате `claude --mcp-config`.

### Прервать и остановить

«Прервать» останавливает текущие ответы и цикл рецензии; сессии сохраняются, и
следующее сообщение их продолжит. Сообщения, ждавшие в очереди, не отправляются.
«Остановить» вдобавок завершает процессы обоих агентов вместе с запущенными ими
командами.

## Настройки

| Настройка | По умолчанию | Назначение |
|---|---|---|
| `agentPanel.claudeCommand` | `claude` | исполняемый файл Claude Code; `claude` — взять из расширения Claude Code, иначе из `PATH` |
| `agentPanel.codexCommand` | `codex` | исполняемый файл Codex; `codex` — взять из расширения ChatGPT, иначе из `PATH` |
| `agentPanel.maxAutoRounds` | `3` | сколько проверок разрешено на одну задачу; `0` — каждую передачу подтверждаете вы |
| `agentPanel.reviewEvidenceChars` | `240000` | сколько символов вывода команд уходит рецензенту за одну проверку; длинный вывод передаётся началом и концом с пометкой |
| `agentPanel.taskTokenLimit` | `0` | предел токенов на задачу для обоих агентов; при достижении передача ждёт вас; `0` — без предела |
| `agentPanel.memorySearchCommand` | пусто | команда поиска по памяти проекта |
| `agentPanel.claudeMcpConfig` | пусто | путь к JSON с MCP-серверами для Claude |
| `agentPanel.claudeSettingSources` | `project,local` | какие настройки загружает Claude; пустая строка — все, включая ваши пользовательские хуки |
| `agentPanel.claudePermissionMode` | `bypassPermissions` | режим разрешений Claude по умолчанию; `default` — спрашивать карточками |
| `agentPanel.claudeWeeklyUsage` | `true` | показывать долю недельного лимита Claude (панель спрашивает `claude -p /usage` не чаще раза в 5 минут) |

Настройки можно задать для пользователя или только для папки проекта
(`.vscode/settings.json`).

## Где хранятся данные

Журнал комнат — файл SQLite `agent-panel.sqlite` в хранилище расширения VS Code. На
Windows это `%APPDATA%\Code\User\globalStorage\local.agent-panel\`. Сессии Claude и
ветки Codex хранят сами агенты: в `~/.claude` и `~/.codex`.

## Как это устроено

Панель сама запускает агентов и владеет их сессиями:
- Claude — CLI в режиме `stream-json` через стандартные ввод и вывод;
- Codex — `codex app-server` по JSON-RPC.

Между ними координатор: маршруты сообщений, цикл рецензии, разбор вердикта,
очередь, отпечаток версии файлов. Интерфейс — webview в VS Code; разметка и формулы
(markdown-it, KaTeX) собраны в пакет и работают без интернета.

Подробнее — в [docs/устройство.md](docs/устройство.md). Что и почему менялось —
в [docs/история-изменений.md](docs/история-изменений.md).

## Разработка

```
npm install
npm test          # сборка и все проверки
npm run watch     # пересборка при изменениях
```

`npm test` собирает проект и запускает проверки без VS Code:
- координатор;
- разбор вердикта;
- адаптеры на поддельных процессах агентов;
- отрисовку разметки;
- интерфейс в безголовом Edge или Chrome.

Проверки интерфейса пропускаются, если браузер недоступен.

Для отладки откройте папку `agent-panel` в VS Code и нажмите F5: запустится второе
окно с расширением из исходников.

Скрипты `scripts/*-probe.mjs` запускают настоящих агентов вне VS Code: проверяют
каталоги моделей, разрешения, фоновые команды и полный цикл рецензии. Они тратят
токены ваших аккаунтов.

Код:

| Путь | Что там |
|---|---|
| `src/extension.ts` | точка входа, комната, связь с webview |
| `src/coordinator.ts` | маршруты, цикл рецензии, очередь |
| `src/adapters/` | запуск и протоколы Claude и Codex, остановка процессов |
| `src/verdict.ts` | разбор вердикта рецензента |
| `src/journal.ts` | журнал SQLite |
| `src/snapshot.ts` | отпечаток версии файлов |
| `media/` | интерфейс панели |
| `test/` | проверки |

## Решение проблем

| Что видно | Что сделать |
|---|---|
| в палитре команд нет «Agent Panel» | установите пакет и перезагрузите окно |
| «нужна открытая папка» | откройте папку проекта |
| «Claude не запустился» | установите расширение Claude Code или укажите полный путь в `agentPanel.claudeCommand` |
| «Codex не запустился» | установите расширение ChatGPT или укажите полный путь в `agentPanel.codexCommand` |
| ответ падает с «does not support this model» | CLI агента старее модели сессии; используйте CLI из расширения (значения настроек по умолчанию) или обновите CLI |
| «ждёт вашего решения» с отказами | режим разрешений не позволяет спросить вас (например, `dontAsk`); переключите его на «спрашивать» |

Ошибки самого расширения видны в «Developer: Toggle Developer Tools», служебные
логи агентов — в разделе «Диагностика» внизу панели.

## Ограничения

- Одна комната на окно VS Code.
- Рецензенту запрещена запись файлов, но запуск команд технически не запрещён:
  это оговорено в его инструкции.
- «В этой сессии» не всегда снимает повторный вопрос: команды с
  перенаправлением вывода в файл Claude Code спрашивает снова.
- Доля недельного лимита Claude берётся из текста ответа `/usage`. Если Claude
  Code изменит формулировку, доля пропадёт, но не станет нулём.
- Остановка процессов на macOS и Linux написана, но не проверялась.
