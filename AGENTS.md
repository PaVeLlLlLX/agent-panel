# Правила для агентов в проекте Agent Panel

**Идентификаторы — только ASCII** (правило владельца от 28.09.2026). Имена
переменных, функций, классов, свойств, параметров и приватных полей пишутся
латиницей, английскими словами. Комментарии, строки интерфейса, классы CSS,
описания тестов в `test("…")` и документация могут быть русскими.

Код, который хранится строкой (проверки в `test/layout.test.mjs`, выполняемые
в браузере), — тоже код: имена в нём тоже ASCII. Имя свойства в `dataset`
связано с атрибутом `data-*` в разметке и селекторах: меняйте их вместе.

Проверка входит в `npm test` (`test/ascii-identifiers.test.mjs`). Отдельно:
`node scripts/ascii-identifiers.mjs` — код выхода 1, если найден идентификатор
не в ASCII; `--list` печатает такие имена. Переименование делайте инструментом
(`--apply`) и сверяйте `--signature` до и `--compare` после: каждое имя должно
разрешаться в то же объявление. Старые имена из прежних записей —
`docs/research/2026-09-28-ascii-identifiers-map.json`.
