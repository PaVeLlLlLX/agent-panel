# Правила для агентов в проекте Agent Panel

**Идентификаторы — только латинские буквы, цифры и подчёркивание**
(`[A-Za-z_][A-Za-z0-9_]*`; у приватных полей — синтаксический `#`). Это правило
владельца от 28.09.2026. `$` — тоже ASCII, но в правило не входит. Имена
переменных, функций, классов, свойств, параметров и приватных полей пишутся
английскими словами. Комментарии, строки интерфейса, классы CSS, описания
тестов в `test("…")` и документация могут быть русскими.

**Код в строках — тоже код.** Скрипт, который выполняется в браузере и хранится
строкой, размечается `` js`…` ``, страница со скриптами — `` html`…` ``
(`test/layout.test.mjs`). Проверка и переименование видят имена в них.
`open()` принимает только размеченную проверку. Имя свойства в `dataset`
связано с атрибутом `data-*` в разметке и селекторах: меняйте их вместе.

**Проверка** входит в `npm test` (`test/ascii-identifiers.test.mjs`). Отдельно:
`node scripts/ascii-identifiers.mjs` — код выхода 1, если какое-то имя нарушает
правило; `--list` печатает такие имена.

**Переименование** — только инструментом: `--signature` до, `--apply`,
`--compare` после.

Что гарантирует `--compare`:
- **Имя, которое TypeScript разрешает,** указывает на то же объявление, что и
  раньше. Импорты тестов из `../out` сверяются с исходниками в `src`.
- **Неразрешённое имя** (свойство нетипизированного значения) проверяется
  слабее: одно старое имя должно стать одним новым во всех местах.
- **В объектах, классах и интерфейсах** не появилось повторов имён членов.

`--compare` не проверяет:
- обращения к свойствам по строке (`obj["…"]`, `data-*` в селекторах);
- код внутри `` js`…` ``/`` html`…` ``.

Их покрывают тесты. Старые имена из прежних записей —
`docs/research/2026-09-28-ascii-identifiers-map.json`.
